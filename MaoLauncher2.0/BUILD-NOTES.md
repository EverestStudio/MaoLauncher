# Build and status notes

This is the current source snapshot from the local MaoLauncher desktop project, version 0.1.12.

Electron app: Minecraft/Fabric installation and launch, managed mod downloads, profiles, game settings, console, server status, map, tutorial, social panel, and UI assets.

Build with Node.js 22+: `npm ci`, then `npm start` or `npm run build:win`.

A real Windows installation and full game session must be validated on Windows. Release signing keys are not part of this repository.
