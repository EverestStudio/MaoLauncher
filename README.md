# MaoLauncher

Репозиторий содержит исходники MaoLauncher, Windows-установщик и GitHub Actions для сборки релизов.

## Проекты

- `MaoLauncherNew/` — актуальные исходники Electron-лаунчера.
- `MaoLauncher-Setup/` — Windows bootstrapper. При каждом запуске он проверяет последний GitHub Release, скачивает и устанавливает новую версию при необходимости, проверяя ZIP по SHA-256. Если обновления нет — запускает установленный лаунчер.
- `.github/workflows/release.yml` — ручная сборка и публикация версионного релиза с архивом лаунчера, SHA-256 и установщиком.

## Выпуск новой версии

1. Открой вкладку **Actions** репозитория.
2. Выбери **Build and publish MaoLauncher**.
3. Нажми **Run workflow**.
4. Введи новую версию, например `2.0.0` (допускается `v2.0.0`).

Workflow проверит версию, соберёт Windows x64 лаунчер и установщик и автоматически создаст GitHub Release и тег. Версия должна быть выше последнего опубликованного релиза.

В опубликованном релизе будут три файла:

- `MaoLauncher-X.Y.Z-win-x64.zip` — архив основного лаунчера;
- `MaoLauncher-X.Y.Z-win-x64.zip.sha256` — SHA-256 архива;
- `MaoLauncher-Setup.exe` — установщик/обновлятор.

Для пользователя достаточно один раз запустить установщик и далее запускать MaoLauncher через ярлык **MaoLauncher** на рабочем столе: этот ярлык запускает установщик, который проверяет обновления перед запуском игры.
