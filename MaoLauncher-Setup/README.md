# MaoLauncher Setup

Windows bootstrapper для репозитория `EverestStudio/MaoLauncher`.

## Поведение установщика

При каждом запуске установщик:

1. Запрашивает последний опубликованный GitHub Release.
2. Сравнивает его версию с установленной версией из `launcher.version`.
3. Если лаунчер уже установлен и версия актуальна — запускает его без повторной загрузки.
4. Если опубликована более новая версия или лаунчер ещё не установлен — скачивает ZIP `MaoLauncher-X.Y.Z-win-x64.zip`.
5. Скачивает соответствующий файл `.sha256` и проверяет SHA-256 архива.
6. Безопасно распаковывает архив, заменяет файлы лаунчера с резервной копией, записывает новую версию и запускает MaoLauncher.

Установка выполняется в `%LOCALAPPDATA%\Programs\MaoLauncher`. Сам установщик сохраняет рабочую копию в `%LOCALAPPDATA%\Programs\MaoLauncherSetup` и создаёт ярлык на рабочем столе, который запускает именно установщик — поэтому проверка обновлений выполняется при каждом старте с ярлыка. Настройки и игровые файлы хранятся отдельно от папки приложения.

## Сборка установщика вручную

Требуется Windows и .NET 10 SDK:

```powershell
dotnet publish .\MaoLauncher.Setup.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Исходники интерфейса установщика находятся в этой папке. Иконки и фоновое изображение берутся из `MaoLauncherNew/assets`.

## Публикация новой версии

Релиз собирается вручную через GitHub Actions:

1. Открой вкладку **Actions** репозитория.
2. Выбери workflow **Build and publish MaoLauncher**.
3. Нажми **Run workflow**.
4. Введи версию в формате `2.0.0` (можно и `v2.0.0`) и подтверди запуск.

Workflow проверяет формат и уникальность версии, а также что она выше последнего опубликованного релиза. Затем он временно задаёт эту версию в `MaoLauncherNew/package.json`, собирает Windows x64 лаунчер и установщик и публикует GitHub Release с тремя файлами:

- `MaoLauncher-X.Y.Z-win-x64.zip` — архив основного лаунчера;
- `MaoLauncher-X.Y.Z-win-x64.zip.sha256` — контрольная сумма архива;
- `MaoLauncher-Setup.exe` — установщик с проверкой и установкой обновлений.

Git-тег и GitHub Release создаются автоматически. Вручную менять версию в исходниках или создавать тег не нужно. Установщик использует публичный GitHub Releases API и не требует токена на компьютере пользователя.
