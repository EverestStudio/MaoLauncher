# MaoLauncher 2.0

Current Electron application: MaoLauncher 0.1.12.

The current source code is being imported into `MaoLauncher2.0/` from the development workspace. Existing launcher and setup projects are preserved.

Windows builds require Node.js 22, `npm ci`, then `npm run build:win` in the application directory. The output is an NSIS installer in `dist/`.
